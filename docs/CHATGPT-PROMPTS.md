# ChatGPT prompt pack — 8 stills · 8 edits · 8 videos

Tuned for ChatGPT's image generation and Sora. Same rules as
[AI-IMAGERY.md](AI-IMAGERY.md): these are concept visuals for the allowed slots
only, never proof of real work, and everything ships with the AI CONCEPT label.

## How to run this in ChatGPT (read first — it changes your results)

1. **One conversation for the whole pour sequence.** ChatGPT's biggest
   advantage is in-thread consistency: once the master image exists in the
   chat, every edit and stage that follows can reference "the same scene".
   Don't scatter the stages across separate chats.
2. **Ask for landscape every time.** Say "widescreen landscape format" in the
   request; ChatGPT's landscape output (~1536×1024) is what we want. The hero
   gets cropped wider by me afterwards — don't fight for 21:9 in the tool.
3. **State exclusions in the prompt.** There's no negative-prompt box; the
   sentence "there is no text, lettering, signage or logos anywhere in the
   image" belongs inside every prompt, and it's already written into each one
   below.
4. **Faces at a distance.** Every prompt keeps workers mid-distance or turned
   away. If a face comes out mangled, don't re-roll the whole image — use an
   edit: "fix this worker's face" or "turn this worker away from camera".
5. **Download full resolution PNGs**, name them exactly as given, drop them in
   `allscope-site/incoming-photos/`.

Every prompt below is complete — copy the whole block including the first
line.

# PART B — the eight edits

Run these **in the same conversation as the master (A5)**, or upload the
referenced image first. Edits 1–7 derive the other stages from the master —
this is what makes the animation feel like one place over one day. Edit 8
creates the hero's "before" from the hero's "after".

**Paste this context preamble before every edit** (with the master attached).
It tells the model what the sequence IS, which measurably improves
consistency:

> Context for this task: we are creating an 8-stage visual time sequence of
> ONE concrete pour on ONE suspended deck, photographed from a single
> locked-off tripod camera across a single day — empty formwork at first
> light through to the finished cured slab. The frames become stages of a
> scroll-driven animation, so consistency between stages is the single most
> important requirement: same deck, same camera position, height and framing,
> same background skyline and tower cranes, same orange mesh edge-protection
> screens along the perimeter, same colour grade. The attached image is the
> MASTER (Stage 5 of 8, the pour in progress). Your task is to create Stage
> [N] of 8, "[STAGE NAME]", as described below, changing only what the stage
> requires and keeping everything else identical to the master.

Recommended order after the master: Edit 1 (SET OUT), Edit 4 (MOBILISE),
Edits 2–3, then 5–7 — each new request can also reference the nearest
completed stage for even less drift. Adjust the light per stage: stages 1–3
earlier and cooler than the master, stage 6 later and warmer, stage 7 dusk,
stage 8 next-morning gold.
